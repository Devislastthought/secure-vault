Secure Vault System – Linux Shell Scripting Lab
📌 Project Overview

The Secure Vault System is a Linux-based shell scripting project designed to simulate real-world cybersecurity practices.
It securely stores sensitive files, enforces strict access control, allows controlled updates, and monitors security risks.

This project was completed as part of an ungraded Shell Scripting Lab for CyberSec Ops, focusing on:

File management

Permissions and access control

Secure scripting practices

System monitoring
